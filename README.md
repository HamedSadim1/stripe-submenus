# Stripe Submenus

A modern, responsive React application featuring dynamic submenus inspired by Stripe's navigation design. Built with TypeScript and Vite for optimal performance and developer experience.

## 🚀 Features

- **Responsive Design**: Adapts seamlessly to different screen sizes
- **Dynamic Submenus**: Hover-activated dropdown menus with smooth animations
- **Mobile-Friendly Sidebar**: Collapsible navigation for mobile devices
- **TypeScript Support**: Full type safety and better development experience
- **Modern UI**: Clean, professional interface with smooth transitions

## 🛠️ Technologies Used

- **React 19** - Latest React with concurrent features
- **TypeScript** - Type-safe JavaScript
- **Vite** - Fast build tool and development server
- **React Icons** - Beautiful icon library
- **CSS Variables** - Custom properties for consistent theming

## 📦 Installation

1. Clone the repository:

   ```bash
   git clone https://github.com/yourusername/stripe-submenus.git
   cd stripe-submenus
   ```

2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

4. Open [http://localhost:5173](http://localhost:5173) in your browser.

## 🏗️ Build for Production

```bash
npm run build
```

## 📱 Usage

- **Desktop**: Hover over navigation items to reveal submenus
- **Mobile**: Click the hamburger menu to open the sidebar
- Navigate through different sections: Products, Developers, Company
